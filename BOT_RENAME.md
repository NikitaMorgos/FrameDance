# Как переименовать бота в Telegram (BotFather)

Чтобы бот назывался **FrameDance** и имел юзернейм **@FrameDance_bot**, сделай следующее.

## 1. Открой BotFather

В Telegram найди **@BotFather** и открой чат.

## 2. Выбери своего бота

Отправь команду:

```
/mybots
```

В списке выбери текущего бота (тот, что был Dancelot).

## 3. Смени имя (отображаемое)

- Нажми **Edit Bot** → **Edit Name**.
- Введи новое имя, например: **FrameDance**.
- Подтверди. Это имя будет видно в профиле бота и в чате.

## 4. Смени юзернейм (@username) — опционально

- В том же меню бота: **Edit Bot** → **Edit Username**.
- Введи желаемый юзернейм, например: **FrameDance_bot**.
- Если имя свободно, BotFather его закрепит. Юзернейм можно менять не чаще чем раз в какое-то время (ограничение Telegram).

**Важно:** после смены юзернейма старый (@Dancelot_bot) перестанет работать. Все ссылки и упоминания нужно обновить на **@FrameDance_bot**.

## 5. Обнови проект

- В **.env** (локально) задай:  
  `BOT_USERNAME=FrameDance_bot`  
  (или тот юзернейм, который указал в BotFather).
- В **Render** (если бот там): в Environment измени **BOT_USERNAME** на **FrameDance_bot** и при необходимости сделай **Manual Deploy**.

Токен бота при переименовании **не меняется** — TELEGRAM_BOT_TOKEN оставляешь тем же.

## 6. GitHub Pages и репозиторий

Если переименуешь репозиторий на GitHub в **FrameDance**:

- URL репо станет: `https://github.com/NikitaMorgos/FrameDance`.
- GitHub Pages: в настройках репо **Settings** → **Pages** проверь, что источник по-прежнему ветка **main**, папка **/docs**. Адрес станет: `https://nikitamorgos.github.io/FrameDance/`.
- В Render при переименовании репо нужно заново подключить репозиторий **FrameDance** или обновить ссылку в настройках сервиса.

Готово: бот будет отображаться как FrameDance, логин и ссылки будут использовать новый юзернейм.
