# Как добавить FrameDance на экран iPhone

1. Открой **Safari** на iPhone (иконка с сайта добавляется только из Safari).
2. Перейди на сайт: **https://framedance.ru** (или http://localhost:3000 для проверки).
3. Нажми кнопку **«Поделиться»** внизу экрана (квадрат со стрелкой вверх).
4. В меню выбери **«На экран „Домой“»** (Add to Home Screen).
5. При желании измени название под иконкой (по умолчанию — «FrameDance») и нажми **«Добавить»**.

После этого на главном экране появится иконка FrameDance. Нажатие откроет сайт в полноэкранном режиме без панели Safari — как приложение.

**Совет:** Если хочешь, чтобы с экрана открывался сразу личный кабинет после входа, добавь на экран страницу **https://framedance.ru/app** (предварительно войди в аккаунт в Safari).
