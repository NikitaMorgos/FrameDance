# Настройка DNS для framedance.ru на Nic.ru

Чтобы сайт открывался по **https://framedance.ru**, нужно добавить две записи в DNS на Nic.ru.

---

## Маршрут по инструкции поддержки Руцентра (основной)

Поддержка Nic.ru указала точный путь к редактированию записей:

1. В **личном кабинете** открой раздел **«Активные услуги»** (часто это в левом меню или внутри **«Заказы»** / **«Услуги»**).
2. Выбери **«DNS-хостинг»**.
3. Нажми кнопку **«Управление DNS-зонами»**.
4. Выбери домен **framedance.ru** и добавь нужные записи (CNAME для www, A для @).
5. В **правом верхнем углу** нажми **«Выгрузить зону»**. Через несколько минут записи попадут на DNS-серверы; распространение по интернету — до часа и больше.

**Если в «Активные услуги» нет «DNS-хостинг»** — значит, услугу DNS-хостинга ещё не заказывали. Тогда:
- Зайди в **Домены** → **DNS-хостинг** (с главного сайта) и оформи заказ одного из тарифов (S, M, L и т.д.);
- для домена framedance.ru в **Домены** → список доменов → **Изменить** у столбца DNS → выбери **DNS-master** → **Сохранить изменения**;
- после появления услуги в «Активные услуги» → **DNS-хостинг** → **Управление DNS-зонами** появится и framedance.ru.

Для работы с DNS-хостингом домен должен быть делегирован на DNS-серверы Руцентра, например:  
`ns3-l2.nic.ru`, `ns4-l2.nic.ru`, `ns8-l2.nic.ru`, `ns4-cloud.nic.ru`, `ns8-cloud.nic.ru`  
(при выборе **DNS-master** для домена нужные серверы назначаются автоматически.)

## Маршрут «куда зайти» (после переключения на DNS-master)

Если домен framedance.ru уже переведён на DNS-master и прошло несколько часов:

### Способ 1 — через верхнее меню «Домены»

1. Открой **https://www.nic.ru/** и войди в личный кабинет.
2. В **верхнем меню** нажми **«Домены»**.
3. В выпадающем меню выбери **«Мои домены»** или **«Список доменов»** (то, что ведёт к списку твоих доменов).
4. В списке найди **framedance.ru** и нажми на **название домена** (или на ссылку «Управление» рядом).
5. Откроется страница домена. Ищи на ней одну из ссылок:
   - **«Управление зоной»**
   - **«Редактировать зону»**
   - **«Перейти к редактированию зоны»**
   - или вкладку **«Зона»** / **«DNS-записи»**
6. Нажми эту ссылку/вкладку — откроется список DNS-записей и кнопка **«Добавить запись»**. Дальше см. шаги 3–4 ниже.

### Способ 2 — через DNS-хостинг

1. Открой **https://www.nic.ru/** и войди в личный кабинет.
2. В верхнем меню **«Домены»** → в выпадающем списке в блоке **«Для работы домена»** нажми **«DNS-хостинг»**.
3. Если откроется **каталог тарифов** (карточки «Тариф S», «Тариф М») — значит, ты на странице покупки. Нужен раздел, где перечислены **подключённые** домены. Попробуй:
   - в левом меню личного кабинета найти **«Услуги»** → **«DNS-хостинг»** или **«DNS-master»**;
   - или вверху перейти в **«Заказы»** / **«Услуги»** и найти услугу DNS для framedance.ru.
4. В списке услуг/доменов выбери **framedance.ru** и открой **«Управление зоной»** / **«Редактировать зону»**.
5. Откроется список записей — нажми **«Добавить запись»** и добавь две записи (см. ниже).

Если в «Домены» → framedance.ru нет пункта «Управление зоной», а в DNS-хостинге framedance.ru не появляется — возможно, делегирование ещё не обновилось; подожди ещё 1–2 часа или напиши в поддержку Nic.ru.

### Если ты уже на странице «Управление DNS-серверами»

Ты нажал «Изменить» у столбца DNS у framedance.ru и видишь выбор «DNS-master», «Статусная страница» и т.д. Это не то место, где добавляют A/CNAME — здесь только выбирают, кто обслуживает DNS.

- На **этой же странице** поищи выше или ниже ссылку: **«Управление зоной»**, **«Редактировать зону»**, **«DNS-записи»** — нажми её, откроется список записей и «Добавить запись».
- Если такой ссылки нет: в левом меню нажми **«Домены»** → в списке снова открой **framedance.ru** и на странице домена ищи отдельную ссылку **«Управление зоной»** (рядом с блоком DNS или в действиях).
- Альтернатива: **«Заказы»** или **«Услуги»** в меню → найти услугу **DNS-master** для framedance.ru → открыть → **«Управление зоной»**.

## Шаг 1. Войти в панель Nic.ru

1. Открой **https://www.nic.ru/**
2. Нажми **Войти** (правый верхний угол) и авторизуйся.
3. Перейди в **Личный кабинет** / **Менеджер** (часто это **https://www.nic.ru/manager/**).

---

## Шаг 2. Открыть управление DNS домена

1. В кабинете найди раздел **«Мои домены»** или **«Домены»**.
2. В списке выбери домен **framedance.ru** и открой его (клик по названию или «Управление»).
3. Нужен раздел **«DNS-серверы»** / **«Управление зоной»** / **«DNS-хостинг»**:
   - Если есть пункт **«Управление зоной»** или **«Редактировать зону»** — нажми его.
   - Если видишь **«DNS-хостинг»** — зайди в него, затем выбери **framedance.ru** и открой **«Управление DNS-записями»** / **«Редактировать зону»**.
4. Откроется список записей (A, AAAA, CNAME, MX и т.д.). Должна быть кнопка **«Добавить запись»** / **«Добавить новую запись»**.

---

## Шаг 3. Добавить запись для www (CNAME)

1. Нажми **«Добавить запись»** / **«Добавить новую запись»**.
2. Выбери тип **CNAME**.
3. Заполни:
   - **Имя / Host / Поддомен:** `www` (без framedance.ru, только www).
   - **Значение / Цель / Canonical name:** `framedance.onrender.com.`  
     Важно: в конце **точка** — `framedance.onrender.com.`
4. Сохрани запись (кнопка **«Сохранить»** / **«Добавить»**).

---

## Шаг 4. Добавить запись для корня framedance.ru (A)

На Nic.ru для корневого домена (framedance.ru без www) обычно используют **A-запись**, а не CNAME.

1. Снова нажми **«Добавить запись»**.
2. Выбери тип **A**.
3. Заполни:
   - **Имя / Host:** `@` или оставь пустым (это и есть «корень» домена framedance.ru).
   - **Значение / IP-адрес:** `216.24.57.1`
4. Сохрани запись.

---

## Шаг 5. Выгрузить зону

- По инструкции Руцентра: нажми **«Выгрузить зону»** в **правом верхнем углу** страницы. Через несколько минут записи попадут на DNS-серверы; обновление по интернету — до часа и более.
- Если такой кнопки нет, поищи **«Сохранить изменения зоны»** внизу или сохраняй каждую запись отдельно.

---

## Итог: что должно быть в зоне

| Тип   | Имя (Host) | Значение                 |
|-------|------------|--------------------------|
| CNAME | www        | framedance.onrender.com. |
| A     | @ (или пусто) | 216.24.57.1          |

---

## Шаг 6. Подождать и проверить

- Изменения DNS на Nic.ru могут примениться от **5–15 минут** до **24 часов**.
- Через 15–30 минут открой в браузере **https://framedance.ru** и **https://www.framedance.ru**.
- В Render (Settings → Custom Domains) статус домена должен стать зелёным (Verified).

После этого добавь в Render переменную **SITE_URL** = `https://framedance.ru`, сделай Manual Deploy и укажи домен в BotFather (см. [PUBLISH_FRAMEDANCE_RU.md](../PUBLISH_FRAMEDANCE_RU.md)).
