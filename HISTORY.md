# История проекта (Dancelot → FrameDance)

Проект изначально разрабатывался под названием **Dancelot**. Папка и репозиторий переименованы в **FrameDance**; функциональность та же.

## Что было сделано под именем Dancelot

- **Telegram-бот** — приём видео рекапов с подписью, сохранение в базу (стиль, уровень, навык, заметки). Команды `/list`, `/login`, меню.
- **Веб-сайт** — вход по ссылке из бота (`/login`), дашборд с рекапами, фильтры по стилю, просмотр заметок и видео.
- **База данных** — SQLite (`data/framedance.db`), структура по стилю / уровню / типу навыка.
- **Деплой** — инструкции и конфиг для Render.com (бот + веб в одном процессе).
- **GitHub** — репозиторий, публикация, GitHub Pages для статики.
- **Документация** — README, DEPLOY.md, GITHUB.md, BOT_RENAME.md, CONTRIBUTING.md.

## Переименование

| Было (Dancelot)     | Стало (FrameDance)   |
|--------------------|----------------------|
| Папка/репо Dancelot| Папка/репо FrameDance |
| Бот @Dancelot_bot  | Бот @FrameDance_bot  |

Подробности смены имени и юзернейма бота в Telegram: [BOT_RENAME.md](BOT_RENAME.md).

Токен бота при переименовании **не меняется** — в `.env` и на Render обновляется только `BOT_USERNAME=FrameDance_bot`.
