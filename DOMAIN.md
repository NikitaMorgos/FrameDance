# Домен framedance.ru — привязка к сайту

Сайт FrameDance можно открывать по адресу **https://framedance.ru**. Ниже — как привязать домен к хостингу и боту.

## 1. Хостинг (например Render)

Если бэкенд уже на **Render** (бот + сервер):

1. Зайди в **Dashboard** → свой сервис FrameDance → вкладка **Settings**.
2. В блоке **Custom Domains** нажми **Add Custom Domain**.
3. Введи **framedance.ru** и при необходимости **www.framedance.ru**.
4. Render покажет, что прописать у регистратора домена:
   - для **framedance.ru** обычно: CNAME-запись `framedance.ru` → `xxx.onrender.com` (или A-запись, если Render даст IP).
   - для **www** — CNAME `www` → тот же хост Render.
5. В панели управления доменом (где покупал framedance.ru) добавь эти записи. Подожди 5–30 минут (DNS обновляется не сразу).
6. В Render в **Environment** добавь переменную:
   - **Key:** `SITE_URL`
   - **Value:** `https://framedance.ru`
   Тогда бот по команде `/login` будет выдавать ссылку именно на framedance.ru.
7. Сохрани настройки и сделай **Manual Deploy**, если нужно.

После этого сайт будет открываться по **https://framedance.ru**, а вход по ссылке из бота — вести на этот же домен.

## 2. Кнопка «Войти через Telegram» на сайте

Чтобы кнопка «Log in with Telegram» работала на framedance.ru:

1. В Telegram открой **@BotFather** → **/mybots** → выбери бота.
2. **Edit Bot** → **Edit Bot Domain** (или пункт про домен).
3. Укажи домен: **framedance.ru** (без https:// и без пути).

Тогда виджет Telegram будет разрешён для framedance.ru и пользователи смогут входить с лендинга одной кнопкой.

## 3. Локальный запуск (проверка перед деплоем)

Перед настройкой домена можно проверить сайт локально:

```bash
npm run db:init   # один раз, если БД ещё не создана
npm run server
```

Открой в браузере: **http://localhost:3000**

Лендинг — главная страница; после входа (по ссылке из бота или по виджету) откроется база рекапов.

## 4. Фирстиль и лендинг

Сейчас в проекте:

- **Главная:** `public/index.html` — страница входа (лендинг). Сюда можно подставить готовый фирстиль: заменить/дополнить стили, логотип, блоки.
- **Приложение:** `public/app.html` — база рекапов для авторизованных пользователей.

Когда будет готов макет/фирстиль, достаточно обновить разметку и CSS в `public/index.html` (и при необходимости добавить картинки в `public/`).
